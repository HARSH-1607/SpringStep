# SpringStep 🏃‍♂️💨


**SpringStep** is a fast-paced 2D platformer made in Unity, now featuring intense combat and boss fights!

🕹️ **[Play the Game Here!](https://play.unity.com/en/games/705ef93a-807a-4ca3-856b-73f6e2e84597/springstep)**


## 🎮 Controls
- **A / D** or **Left / Right**: Move
- **Space**: Jump (Double Jump supported!)
- **V**: Dash
- **J** or **Left Click**: Melee Attack
- **Q**: Ultimate Water Projectile (Costs 5 Score Points)

## 🌟 Features
- **Dynamic Movement**: Fast-paced platforming with double jumps, dashing, and trampoline bounces.
- **Combat System**: Chain melee attacks and utilize powerful water projectiles to defeat enemies.
- **Epic Boss Battles**: Face off against SATYR the Destroyer! Manage your accumulated score to fire projectiles and dodge his devastating Leap Slams.
- **Level System**: Progression through multiple challenging platforming stages.
- **Score System**: Collect coins to build your score across levels—use it as currency for your Ultimate attacks.
- **Trampolines**: Bouncy platforms to reach new heights.

## 🛠️ Development
Created as a demo project to explore:
- Unity 2D Physics & Robust Ground Detection
- Scene Management (Menu -> Gameplay -> Boss -> Win)
- Persistent Data (Singleton GameManager for Score Tracking)
- Advanced Boss AI State Machines (Phases, Projectiles, Screen Shakes)
- Custom Input Handling

## 📦 Installation
1. Clone the repo.
2. Open the project in Unity (Version 2022.3 or later recommended).
3. Open `Assets/Scenes/Menu` to start playing.
